Project Overview

My project explores a browser-based musical garden designed for toddlers and young children with limited language skills. The interface uses familiar garden objects and direct interaction instead of written instructions or technical music controls. Children can press and hold a flower to produce sound, or drag it towards a matching shadow while exploring how movement changes the sound.

For my parallel prototypes, I explored two design areas: Visual Feedback and Spatial Input. Visual Feedback investigates how changes such as scale, glow and animated musical notes can communicate that an object has been activated. Spatial Input explores how dragging the flower through the interface can control different sound qualities such as pitch, volume and timbre.

These design areas connect to the project values of Playfulness, Curiosity and Accessibility. The prototypes allow different interaction approaches to be compared while keeping the main task and interface consistent, helping me investigate how the musical garden can support understandable and playful sound exploration.

Design Area 1: Visual Feedback

My first design area explores how visual feedback can communicate interaction in the musical garden without relying on written instructions. When the flower is pressed and produces sound, the visual response should be noticeable and help create a clear connection between the child's action, the visual change and the sound.

I focused on noticeability, cause and effect, interaction states and playfulness. The feedback should make it clear when the flower is active and when the interaction has ended, while also encouraging curiosity without becoming distracting. To explore this, I developed three parallel prototypes: Scale Feedback, Glow Feedback and Musical Note Feedback, while keeping the flower, sound interaction and basic interface consistent.

Prototype 1: Glow Feedback

This prototype uses glow to communicate that the flower is active. When the flower is pressed and held, a glow appears around it while the sound is playing. This explores whether visual highlighting can clearly show the active state without changing the flower's size or position.

Prototype 2: Musical Note Feedback

This prototype uses animated musical notes as continuous visual feedback. Notes appear while the flower is held and stop being generated when it is released. This explores whether animated feedback can make the interaction more playful and clearly communicate ongoing sound without becoming visually distracting.

Prototype 3: Scale Feedback

This prototype uses scale as direct visual feedback. When the flower is pressed and held, it becomes larger while producing sound, then returns to its normal size when released. This explores whether changing the object itself creates a clear and immediate connection between the child's action, the visual response and the sound.

Design Area 2: Spatial Input

My second design area explores Spatial Input, the extended technique carried forward from Assignment 1, and how movement can control sound without using technical music controls. In all three prototypes, the child drags a flower towards a matching shadow while movement changes the sound. The matching task remains consistent while the mapping changes: horizontal position controls pitch, vertical position controls volume, and distance from the centre controls timbre. This allows me to compare how understandable, predictable and exploratory each mapping is.

Prototype 4: Horizontal - Pitch

This prototype maps horizontal movement to pitch. The child drags the flower towards its matching shadow while moving left produces a lower pitch and moving right produces a higher pitch. This explores whether a simple directional mapping makes the relationship between movement and sound easy to discover.

Prototype 6: 2D - Timbre

This prototype maps distance from the centre of the screen to timbre. The sound becomes more muffled near the centre and brighter further away. Unlike the other prototypes, this mapping uses movement in both directions, allowing me to explore whether a less obvious spatial relationship can still be discovered through interaction.
